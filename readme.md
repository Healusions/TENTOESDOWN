# TENTOESDOWN

TENTOESDOWN is an alternate-history Hearts of Iron IV campaign centered on an independent Indiana in 1936.

After one common focus, the player chooses among four governments:

- McNutt's Indiana Democrats
- The Harrison Regency
- Pelley's Silver State
- Hapgood's Wabash Congress

Each route has one temporary consolidation category, five one-time operations, and a 70 Political Control threshold. Focuses unlock more operations; decisions do not gate the focus chain.

Taking power does not solve Indiana's crises. The new government must close the Vigo occupation, reissue state authority, resolve its secret Chicago creditors, and break the federal freight holds before the Purdue story begins.

See INSTALL_AND_TEST.txt for installation and a short smoke test. See DESIGN.md for the campaign rules and writing guide.
