# TENTOESDOWN

TENTOESDOWN is an alternate-history Hearts of Iron IV campaign centered on an independent Indiana in 1936.

This build is a ground-up opening rebuild. After one common focus, the player commits to the Harrison Crown, Pelley's Silver State, or Hapgood's Wabash revolt. Each route uses one simple sequential decision category and reaches power through a different method: regency, subversive seizure, or civil war.

Purdue's strategic research appears only after Indiana has a settled government. It begins through accelerator procurement at West Lafayette and provides leverage against the Federal Standoff without granting an immediate atomic weapon.

See `INSTALL_AND_TEST.txt` for installation and a short smoke test. See `DESIGN.md` for the canon, interface budget, and writing rules.
